# コラム分離ルール（曲ページ ↔ 別コラムの振り分け）

learning型の曲ページで、背景・制作・評価のセクションを **曲ページ内に内包するか／別コラムに切り出すか** を判定する恒久ルール。人力の都度判断をやめ、閾値で自動振り分けする（bot実装の判定基準）。

## なぜ分けるのか
- **薄い内容を無理に別記事化しない。** 中身の薄いコラムを乱造するとAdSenseの "Low value content" に逆戻りする。
- **濃い殿堂入り曲だけ分ける価値がある。** 曲ページ＝リリック学習に集中／別コラム＝制作秘話・時代背景・評価。
- 狙い: ①初見が深さを一目で察知 ②回遊増（曲→背景→アーティストの立体内部リンク）でサイトの厚みが出る ③曲ページが軽くなり「長すぎ」が消える。

## 判定対象の3セクション
各 learning型曲ページが持ちうる深掘りセクション:
- **背景**（文化的・時代的背景）
- **制作**（サンプル元・制作秘話・機材・プロデューサーの手法）
- **評価**（チャート・受賞・後世への影響）

この3つを **セクション単位で個別に** 判定する（曲まるごとではない）。

## 閾値（このすべてを満たしたら「別コラム化」）
1. **分量**: そのセクションの日本語解説が **600字以上**。
2. **固有エピソード数**: 裏取り済みの固有エピソードが **2件以上**（例: 制作なら「消えたtouch＝機材ミス」「The Charmelsサンプルの執拗なループ」で2件）。固有＝その曲/アーティスト固有の、一般論でない事実。
3. **事実が裏取り済み**: [`fact-check-rules.md`](fact-check-rules.md) の一次ソース照合を通過していること（裏が取れない話は分量に数えない）。

→ **3条件すべて満たす** = 別コラムに切り出し、曲ページにはDiveCardsの1枚で誘導。
→ いずれか欠ける = 曲ページ内にインライン内包（コラムを作らない）。

## 振り分けの帰結（イメージ）
- **CREAM級（殿堂入り）**: 背景・制作・評価すべて閾値超え → 3セクションとも別コラム、曲ページはDiveCards 3枚で誘導。
- **中間の曲**: 例えば制作だけ濃い → 制作のみ別コラム、背景・評価は曲ページに内包。
- **無名/薄い曲**: どれも閾値未満 → すべて曲ページ内包、コラムは作らない。

## 切り出し時の運用ルール
- 切り出し先コラムは [`src/data/columns.ts`](../src/data/columns.ts) に必ず登録（slug/title/description/tag/relatedSongs）。未登録＝アーティストページ同様ページが生成されない／内部リンク切れ。
- 曲ページからの誘導は [`src/components/DiveCards.astro`](../src/components/DiveCards.astro)（記事末＝動線）と、units前の予告ブロック（読み込む前に）の **2箇所配置** を標準とする。
- DiveCardsのリンク先は **実在するコラムのみ**（デッドリンク厳禁）。コラム未作成なら、そのカードは出さない。
- **既存の確定サンプル散文は文言を壊さない。** cream.astro の散文は記録として文言不変（切り出し＝移動時も改変しない）。ただし**トーン模範としては参照停止**（2026-07-02〜。現行模範は nas-is-like.astro、詳細は [`article-tone.md`](article-tone.md)）。
- 切り出しても **同一/酷似の解説文を曲ページとコラムで二重に置かない**（pre-push の定型句ガードが25字以上の重複を検出）。移動＝片方から消す。曲ページ側はDiveCardsの短い誘導文に置き換える。

## 既存コラムとの突き合わせ
切り出す前に [`src/data/columns.ts`](../src/data/columns.ts) を見て、**既に同テーマのコラムがある場合は新規作成せず既存へ誘導**する（例: 背景＝`crack-epidemic-hiphop`、時代＝`ny-golden-era-1994`、アーティスト＝`wu-tang-clan` は作成済み）。テーマが既存コラムでカバーされていれば曲固有のインラインを薄くして既存コラムへ飛ばすだけでよい。
