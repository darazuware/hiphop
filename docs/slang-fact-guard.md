# スラング語ページの事実ガード（ハルシネーション対策）

入口: `node agent/src/check-slang-all.mjs`（全✅になるまでpushしない。publish-main.mjs からも実行される）

| 検査 | 何を機械で保証するか |
|---|---|
| check-slang-page | 構造・量・文体・定型句の重複 |
| check-slang-facts | `inSongs` の引用（quote）が、歌詞コーパスの該当アーティストの歌詞に**逐語で存在**し、曲名が一致する。`stats` はコーパスの実測から自動生成（`--fix-stats`）で手書き禁止 |
| check-slang-sources | 本文の**年**（1990年代など年代表記は除く）が、`sources` の出典本文に存在する。取得できない出典は `{url, evidence, via}` で抜粋を記録 |

## ルール
- 歌詞の引用は**コーパスに存在する行のみ**。記憶で書かない。コーパスは `agent/corpus`（gitignore・ローカルのみ。`node agent/src/corpus-fetch.mjs --artist 名`）。
- 年・語源・人物の主張は、書く前に一次ソースで確認し `sources` にURLを足す。出典が取れない主張は書かない（「確認できていません」と書く）。
- 例文（examples）は解説用の作例で、歌詞の引用ではない（ページ上にも明記）。作例を実在の曲の歌詞として扱わない。
- 曲ごとの `note`（解釈）は人の読みであり機械検証できない。事実（誰が・いつ・どのアルバム）を断定する場合は上の出典ルールに従う。
