# WAX&THINK 記事トーン定義（運営者の声）

学習ページ・コラムの日本語文章は、**運営者本人が書いたラフな声**で書く。外注ライターが書いたような「ガチガチの説明調」を避ける。事実の厳密さ（[`fact-check-rules.md`](fact-check-rules.md)）は一切緩めない。**トーンはラフでも事実は厳密**を両立させる。

## 理想トーンの実例（C.R.E.A.M. 導入）

> Cash Rules Everything Around Me（金が周りのすべてを支配する）——クラック・エピデミックが蔓延したインナーシティで、金のために生き、金のために死ぬほかない若者たちの絶望を描いた楽曲。『俺はこんなに金持ってんだぜ〜』というFLEX的な拝金主義の讃歌ではなく、貧困の構造的暴力を歌ったクラシック中のクラシック。この記事は英語学習とヒップホップ理解の教材として読んでもらえればと思います。色々いるウータンメンバーの中でもラップするのはRaekwonとInspectah Deck、そしてHOOK担当がメソッドマンという少数精鋭の構成。リリックには、辞書に載らないストリートスラング、AAVE（アフリカ系アメリカ人英語）の文法、二重・三重の意味を仕込んだ言葉遊び、そして韻の構築が凝縮されています。それぞれを『学ぶ表現』単位で取り出し、用例の断片・和訳・語法と文化背景を解説していきたいと思います。

## 理想トーンの実例②（C.R.E.A.M. なぜ教材か）

> ■なぜC.R.E.A.M.が教材として優れるか。1994年リリース。RZAがThe Charmelsの哀愁ピアノをサンプリングし、HOOKをMethod Man、RaekwonとInspectah Deckがヴァースを担当。Wu-Tang Clanで最大のヒットとなり4×プラチナに認定されました。それだけじゃなくなんと"C.R.E.A.M."という単語は後に「現金」を意味するスラングとして英語辞書に収録されたようです。(本場だけあってHIPHOPの影響力すごすぎ）教科書英語からは決して学べない生きたストリート言語の凝縮度と、たった数語に複数の意味を畳み込む言葉の経済性——この2点で、本作はリアルな英語表現の教材として群を抜いています。当時、業界的にはウェッサイ(西海岸)のG-Funk全盛の時代でしたが、スタテンアイランド（＝Shaolin＝少林）から放たれた東海岸の反撃、という文脈も併せて知っておくと面白いと思います。

この実例②から抽出する特徴:
- **括弧書きの素のつぶやき**を差し込む（「(本場だけあって…すごすぎ）」）。本文の硬さを抜く抜け穴。
- **読者への語りかけ**で閉じる（「知っておくと面白いと思います」）。評価で締めず、誘いで締める。
- **「なんと」「それだけじゃなく」**等、驚きをそのまま口語で出す。発見を読者とシェアする温度。
- 運びは軽いが、**事実（年・客演・認定・辞書収録）は厳密**。「〜ようです」などの柔らかい語尾は語りの呼吸であって、裏取り省略の口実にしない（事実は必ず [`fact-check-rules.md`](fact-check-rules.md) で確認）。
- 「群を抜いています」は〈作品の腕前を上から格付け〉ではなく〈**学習素材としての適性**〉を述べる用法なので可（後述の禁止例と区別する）。

[`src/pages/songs/cream.astro`](../src/pages/songs/cream.astro) の**散文セクション全体**（導入「この曲で何を学べるか／なぜ教材として優れるか」・ストーリーの流れ・文化的背景・サンプル/制作の裏側・評価とその後の影響・まとめ）は、**運営者本人が手で書き上げた確定版**であり、本トーン定義の**最上位サンプル**とする。今後の全曲・全コラムの日本語散文は、このcream散文の温度・運び・語彙感を標準として書く。文体ルールと実例①②の上位に、この確定サンプルを置く。

確定サンプルから抽出する具体特徴（実物の言い回しで示す）:

- **ですます基調に常体がスパイスで入る。** 全文を敬体で固めず、断定や描写は常体に落として緩急を作る。例:「両側を悲惨なヴァースに挟まれた瞬間…叫びへ反転する——置かれる場所が語の意味を決めてしまう、その好例です。」「同じ一行でも、どこに置かれるかで意味が変わるわけです。」（常体の描写 → 敬体の締め、を一段落の中で行き来する）
- **賢ぶった評価語を使わず、素の主観で語る。** 審査員的な格付け語を避け、自分が感じたことをそのまま口語で出す。例:「初めて通しで聴いたとき、この畳み方に静かにやられました。」「ここがRZAの真骨頂です。」「もう数字を見るだけで、まさに戦場だったとわかる。」「事実は小説より奇なり、です。」「と言ったら大げさに聞こえるだろうか。でも事実だ。」
- **好きで語る／読者に共有するスタンス。** 〈評価する〉のではなく〈一緒に驚く・面白がる〉。発見をシェアする温度で、読者を巻き込む。
- **専門語・固有名詞の直後に素の言い換えを添える。** 例:「クオンタイズ（リズムの自動補正）をあえて無視する」「Old Earth（…）」「AAVE（アフリカ系アメリカ人英語）」のように、難語のすぐ後に噛み砕きを置いて初心者を置き去りにしない。
- **一文の長短の緩急と、括弧/ダッシュの素のつぶやき。** 「（本場だけあって、HIPHOPの影響力すごすぎ）」のような抜けを差し、硬さを消す。
- **トーンはラフでも事実は厳密。** チャート順位・認定・年・サンプル元・客演は [`fact-check-rules.md`](fact-check-rules.md) で裏取り済みの数値をそのまま使う。トーン調整で事実を曖昧にしない。

> ⚠️ この散文は確定版につき**文言を変更しない**。トーンの基準として参照し、新規記事に同じ温度を再現するために使う。下記「やってはいけないこと」の評論家ヅラ禁止リスト（群を抜く／見事／圧巻／秀逸 等の上から格付け語）は引き続き維持する。

## 文体ルール（必ず守る）

1. **常体（だ・である）を基調に、要所で敬体（です・ます／〜と思います）を混ぜる。**
   常体敬体のゆらぎを許容し、統一を強制しない。これが固さを消す核心。読者に語りかける文（「〜してもらえればと思います」「〜していきたいと思います」）は敬体、断定・描写は常体、と自然に行き来する。**統一しようとして全文を常体や敬体に揃えない。**

2. **作品への熱と敬意を滲ませる。**
   知識のひけらかしではなく、本気で分かっている人の温度で語る。「クラシック中のクラシック」のような率直な評価を恐れない。

3. **リリックの意訳や軽い口語を所々に混ぜて抜けを作る。**
   『俺はこんなに金持ってんだぜ〜』のような砕けた言い換えを括弧書きやカギ括弧で差し込み、固さを抜く。全部を硬い説明語で固めない。

4. **一文の長短に緩急をつける。**
   言い切る短い強さ（「クラシック中のクラシック。」）と、読者に向き直る柔らかい長文の両方を持つ。同じリズムの文を続けない。

5. **固有名詞・専門語の後に素の言い換え・補足を置き、初心者を置いていかない。**
   「AAVE（アフリカ系アメリカ人英語）」「Inspectah Deck、そしてHOOK担当がメソッドマン」のように、専門語のすぐ後に噛み砕きを添える。カタカナ表記（ウータン／メソッドマン）も親しみとして許容する。

6. **（learning型ユニット限定）日本語で語る前に、まず英語の用例を読者に手渡す。**
   各ユニットの本文（解説スロット）は「**①上の英語引用をまず音／目で追わせる → ②行の中のどこが学習対象かを"位置"で指す → ③語法と意味を日本語で解説**」の順で書く。英語が苦手な読者を、いきなり日本語の分析で置き去りにしない。「英語が分かる記者が一人で日本語で興奮している」状態を避け、読者の手を引いて英語に触れさせる。
   - **スラングを単語単体で切り出さない。** まずその語を含む行（1〜2行）を引き、**行の前半／後半／行末／真ん中／2行目…**と"位置"で示す。例:「上の行の最後、"…rockin' the gold tooth, 'Lo goose"——この行末の 'Lo goose が学習ポイント」。読者がラップのどこにその表現があるか分かるようにする。
   - **英語引用量は増やさない。** 用例（eng/jpn スロット）は1〜2行のまま。本文で位置を指すときは、すでに上に出ている断片を短く参照するだけで、行全体を本文に再掲しない。見せ方（順番・指し方）だけを変える。引用最小性［D］と独自性［C］の基準は維持。

## learning型 共通構成ルール（全曲必須・2026-06-13確定）

cream / nas-is-like / 93-til-infinity の実作で判明した、量産時に崩れやすい4点を全曲ルールとして固定する。**新規の曲ページ生成時・既存ページ改稿時に必ず適用する。**

1. **導入見出しを一律テンプレにしない（量産テンプレ臭の回避）。**
   「■なぜ〇〇が教材として優れるか」を全曲に機械的に付けない。同じ見出しの使い回しは独自性評価（AdSense）に逆効果。**導入の切り口・見出しは曲ごとに変える**——その曲固有の魅力・文脈・聴いた時の感触から書き起こす。例: 93-til-infinity は「■重たいNYの後の、極上の箸休め」「■服・靴・天気・週末——"日常の英語"の見本市」のように、曲の中身に即した見出しにした。「この曲で何を学べるか」「なぜ教材か」という枠組み自体は使ってよいが、文言は毎回その曲の言葉で書く。

2. **学習ユニットは曲の時系列順に並べる。**
   冒頭ユニットがタイトル／フックの説明になるのは曲構造上OK。それ以外は曲の進行順（Intro → Verse 1 → Hook → Verse 2 …→ Outro）に並べる。`units.json` も同じ曲順に並べる（whisper前方スキャンが順序依存のため。順序ミスで同一行のV2側へ誤マッチした事故あり＝ny-state cousin-of-death）。nas-is-like・93で時系列が乱れた件の再発防止。

   **網羅性ルール（偏り禁止）。** 学習ユニットは曲の冒頭から終盤まで満遍なく配置し、特定のVerseに偏らせない。曲の総尺に対して最後のユニットが極端に手前（4分の曲で2:30で終わる等）にならないよう必ず確認する。各 Verse／Hook／Bridge／Outro から最低1つは表現を拾う。目安として曲の尺の最後の4分の1（終盤）に必ず1つ以上ユニットを置く。

3. **専門用語にマウスオーバー（タップ）解説を付ける。**
   idiom（イディオム）・AAVE・copula（コピュラ）・habitual be 等の専門用語は、初心者には用語自体が不明。**既存の `QuickSlang` コンポーネントで平易な説明をツールチップ表示する**。日本語の専門語でも `<QuickSlang word="イディオム" desc="..." />` のように使える（中央辞書 `slang.ts` 未登録語は点線下線＋ツールチップのみ＝デッドリンクなしで安全）。各専門語の**初出箇所**に最低1回付ける。

4. **「地元」を固有名詞化する。**
   「地元」「彼らの街」で済ませず、曲ごとの実際の地名を必ず出す。例: Nas＝クイーンズブリッジ、Wu-Tang＝Shaolin／スタテンアイランド、Souls of Mischief＝オークランド／ベイエリア（the Land＝Oakland）。地名はスラングの地域差を体感させる学習素材でもあるので、抽象語で逃げない。

## やってはいけないこと

- 全文を「である」「だ」で締める硬い論文調に揃える（ゆらぎを消す）。
- 専門語を説明なしに連発して初心者を置いていく。
- 評価を避けて事実だけを無味乾燥に並べる（熱を消す）。
- **事実をラフにする**——トーンはラフでも、サンプル・年・チャート順位・客演などの事実主張は [`fact-check-rules.md`](fact-check-rules.md) に従い一次ソースで裏取りする。曖昧表現で逃げない。
- 砕けすぎて品位を失う（スラング解説サイトとしての信頼を損なう過度な俗語・タメ口の乱用）。あくまで「分かっている個人が丁寧に、でも肩肘張らず語る」温度。
- **作品を上から評価・格付けするコラムニスト表現を使わない（評論家ヅラ禁止）。** 「見事としか言いようがない」「群を抜いている（※作品・アーティストの腕前を上から断ずる用法）」「圧巻」「秀逸」など、審査員的に合否を下す構えはNG。運営者は審査員ではなくファン。**〈評価する〉のではなく〈好きで語る／読者と一緒に驚く〉スタンス**で書く（例:「初めて聴いたときやられた」「何度聴いても唸る」「ちょっと鳥肌が立つ」「知っておくと面白いと思います」）。
  - 区別: 「英語教材として群を抜く」のように〈**学習素材としての適性**〉を述べるのは可。禁止なのは〈作品そのものの優劣を上から裁定する〉言い回し。
- **同一／酷似の解説文（定型句）を複数の曲ページで使い回さない。** 運営者の語り口の癖（常体敬体のゆらぎ・括弧の素のつぶやき・読者への語りかけ等）は真似てよいが、**文そのものをコピペ再利用しない**。同じ言い回しが2曲以上に現れた時点でテンプレ臭になり、独自性（[C]）とAdSense評価の両方に逆効果。サンプル／制作の話のまとめ文・締めの一文は、必ずその曲固有の事実（サンプル元・掘った経緯・制作環境）に即して毎回書き起こす。一般論で締めない。
  - 悪い実例: 「お金をかければ出る音、というわけではないのが面白い。」——cream初出が良かったために5曲へコピペ再利用され、定型句化した（2026-06-13に各曲の固有表現へ書き換え済み）。この一文に限らず、25文字以上の解説文の曲間重複は [`agent/src/pre-push-check.mjs`](../agent/src/pre-push-check.mjs) の重複検出ガードが検出してブロックする。

- **格調ぶった評価格付け表現を使わない（評論家ヅラ・具体実例）。** 下記は hold-you-down 初稿で実際に出た崩れ。サンプル・制作・後世の影響セクションは特にこの調子になりやすいので注意する。
  - ❌「（アーティスト名）として広く認知されるようになった」 → ✅ そうなっていった経緯を素の語りで。「ただのビート職人じゃなく、自分の名前でアルバムを背負える人なんだと聴き手に伝わったと思います」
  - ❌「〜節の確立」「〜哲学がよく表れたチョイス」 → ✅「こういう選び方するか、と思った」「種は全部ここに蒔かれてたんだなと分かって面白い」
  - ❌「逆算的に壊してダークな色に塗り替えていく」（格調ぶった分析口調） → ✅ 発見の共有に。「元はこんなに甘い映画音楽なのに、ハードなドラムを乗せると原曲の温かさがすっと冷える。この素材からこの曲に持っていくのか、と元ネタを聴いたとき妙に納得した」
  - ❌「〜として位置付けられる」「〜の先駆けとして評価された」（断定格付け） → ✅「早い時期にやってみせた一枚」「その流れの早い側にいた作品だと思います」
  - 推奨の温度: **「これを知ってから聴くと、また聞こえ方が変わる」「初めて元ネタを聴いたとき妙に納得した」**のような、〈裁定〉でなく〈発見を読者と共有する〉言い回し。

## 適用範囲

- 学習ページ（learning型）の導入文・ストーリー要約・各ユニットの日本語解説・文化背景・まとめ。
- コラム本文。
- **英語引用（eng）・和訳（jpn）スロットの分量は増やさない。** トーン調整は日本語解説部分のみで行う。引用最小性（[D]）と独自性（[C]）の検証基準は維持する。

## 散文の文体ルール（dead-presidents改訂で確定）

実作（dead-presidents）の散文改訂で、AI調・ライター調を消すために効いた具体策を固定する。**全曲・全コラムの散文に適用する。**

### 禁止：価値づけの断定
「書き手が上から評価を配る」断定を散文で使わない。
- 「〜の核だ」「〜の核心だ」
- 「通奏低音だ」
- 「言語の経済性がよく出ている」
- 「リリシズムの核」
- 「〜が確立した」「〜スタイルを確立」（格付け的な達成断言）
- 「〜に根ざしている」「〜の底流にある」（評論家の俯瞰ポジション）
- 「〜路線を譲らなかった」（作品の方針を上から品評）
- 「〜耳に残る」単体での使用（審査員ポジションの評価断言。「最初の数秒で耳が持っていかれる」等の体験寄り表現に置き換え）
- 「〜に限っては〜だ」（限定断定の格付け調）
- 「聴き手が背景を知っているほど多層的に読める」（評論家の分析ポジション。「知ってるほどニヤリとできる」等に置き換え）
- DAJARE（全角英語混じり）→ ダジャレ（日本語）で統一
- その他、評論家が作品を品評する型の言い切り全般

→ 価値を断定せず、引っかかった理由を具体で書くか、感想として一人称で書く。

### 構成：結論先出しをやめる
「Xとは〜である。なぜなら〜。つまり〜」の三段論法を段落の型にしない。教科書的に結論を頭出ししない。引っかかりや具体から入って、読者と一緒に進む。

### 情報密度に粗密をつける
全文を同じ温度・同じ密度で詰めない。
- どうでもいい前置きや種明かしはゆっくり書く
- 経歴・設立経緯など事務的事実は1文で流す

→ 「びっしり感」がAI調の主因。意図的に緩急をつける。

### 感想は対象に近づける
批評家の距離から「〜だと思います」と評するのではなく、好きな人が前のめりで語るように対象に寄る。例:「なかなか食えない始め方です」「音だけ追っても気持ちいい」

### 息継ぎ＝改行を入れる
長い段落を塊で置かない。話題が変わる／間を取りたい箇所で改行して段落を割る。特に引用フレーズの前後、転換点では改行する。
